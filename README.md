# TownBuilds

Плагин для Paper/Spigot 1.20 на сервере **VortexiaPolit**. Синхронизирует Tab-префикс игрока с названием его города [Towny](https://github.com/TownyAdvanced/Towny) при входе/выходе из города, поверх любых других правил TAB-плагинов. Для персонала (модерации) префикс городом не перезаписывается.

## Права

- `townbuilds.use` — базовое использование (по умолчанию: всем).
- `townbuilds.admin` — административные функции (по умолчанию: только ОП).

## Зависимости

- **Towny** (опционально).

## Сборка

```
compile.bat
```

## Совместимость

- Minecraft **1.20.1**
- Ядро сервера: **Mohist 1.20.1** (плагин используется на сервере VortexiaPolit)
- Написан на Bukkit/Spigot API, поэтому может работать и на Paper/Spigot 1.20.x
